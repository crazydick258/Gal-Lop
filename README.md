# Gal-Lop
在GalLop中，你可以用你自己的想法制作一部galgame，无需任何编程基础，就像制作PPT一样简单。如果你不会制作PPT，可以用AI生成一份，在GalLop中你也可以这样做。

## 核心功能

### 1. 创作端

#### 流程图编辑器
- 完全基于 Compose Canvas 手绘的节点编辑器，支持拖拽、缩放、平移
- 支持多种节点类型：**对话节点**、**纯文本节点**、**CG 节点**、**游戏节点**、**网页节点**
- **连接模式**：点击源节点再点击目标节点创建跳转
- **切断模式**：拖拽绘制切割线批量删除连接
- **对话集（Archive Group）**：可将多个节点收纳为可折叠的壳，支持内部独立编辑
- 支持 **辐射布局（Radiation）** 和 **链式布局（Chain）** 两种排列模式
- 内置撤销 / 重做
- 节点可标记为 **开局节点**、**结局节点**，支持多结局分支

#### 对话编辑器
- 为对话节点配置立绘、背景、BGM、语音
- 支持角色立绘的 **布局定位保存**
- 对话文本与选项的富文本编辑
- 自动插入（Auto Insert）：基于素材池匹配素材

#### AI Agent 智能导演工作台
- 导入纯文本剧本，AI 自动完成：
  - 语义解析与角色识别
  - 场景匹配与立绘生成
  - 完整工程草稿构建
- 支持流式输出，实时展示生成进度
- 多轮对话式 Agent 调试日志

#### 小游戏工作室（Mini Game Studio）
- 导入 HTML5 小游戏（`.html` / `.htm`），封装为可嵌入游戏节点
- 自动注入 Gal Lop Bridge API，实现小游戏与主流程的通信（`finishGame` / `finishGameWithResult`）
- 支持 `window.GalLop` ready 回调与视口自动适配

#### 网页节点
- 支持嵌入外部 URL 为内容节点
- 可切换 **GeckoView**（Firefox 内核）或**系统 WebView** 渲染
- 可选桌面浏览或移动端浏览（都是横屏）

#### 素材池（Material Pool）
- 统一管理作品内的图片、音频等素材
- 支持 AI 生成图片、AI 生成音频（需配置API）
- 素材自动分类与标签

#### 变量与规则系统
- 支持自定义变量（整数、字符串、布尔）
- 支持条件规则（对话级 / 全局级）
- 规则可绑定到对话选项，决定跳转分支

#### 导入 / 导出
- **导入**：支持 TXT、EPUB 纯文本书籍
- **导出**：作品完整包（ZIP）导出、加密包导出
- **WLAN 分享**：同局域网下设备间无线传输作品

### 2. 阅读端（播放器）

- 完整的视觉小说游玩体验
- 支持 **自动阅读**（可配置速度）
- **存档系统**：多个存档槽位，支持存档 / 读档
- **回溯**：返回上一次选项重新选择
- **多结局支持**：结局选项可配置退出、重开或返回上一步
- **主界面菜单**：可定制菜单界面（继续 / 新游戏 / 载入 / 退出）
- 阅读器内可直接查看流程图概览并跳转到指定节点
- BGM 跨节点无缝播放

### 3. 书架

- 展示所有本地作品
- 支持作品封面、简介管理
- 批量操作：删除、导出

### 4. 设置

- **主题**：浅色 / 深色
- **流程图节点顺序**： 辐射判断/方向判断
- **阅读器背景长按**： 无操作/存档/打开流程图预览/快进对话
- **自动阅读速度**
- **新建对话沿用图像 / BGM 继承**
- **网页节点渲染内核选择**（GeckoView / 系统 WebView）
- **GeckoView 内核下载配置**
- **AI API 配置**：API 地址、API 密钥、模型名称
